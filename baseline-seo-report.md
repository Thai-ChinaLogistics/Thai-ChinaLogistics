# Baseline SEO report — 2026-09-21

## Observed

- 22 HTML files were found; 21 public URLs are listed in the sitemap.
- All 21 public pages have one title, one meta description, one H1, one canonical and one JSON-LD block in the current checkout.
- Title and description values are unique across the 22 HTML files audited.
- The homepage has canonical and JSON-LD, and its five referenced Hero assets exist locally.
- `robots.txt` allows crawling and points to the canonical sitemap.
- The homepage contains the PRD-required direct answer, route/service sections, process, pricing logic, cargo caveats, cases, FAQ, CTA and a multi-field inquiry form.
- The form fields cover name, contact type/value, city, destination, cargo, weight, size, pickup path and note. The active runtime sends the lead through the configured tracker and opens WhatsApp; no real submission was performed.

## Evidence limits

- No local GSC export or authenticated GSC session was available, so current impressions, clicks and rankings are `UNAVAILABLE` and were not invented.
- No production publish authorization was provided; the deployed public state is not claimed.
- Mobile and low-speed visual checks were not completed in this pass because the available browser bridge could not apply a mobile viewport to the local page.

## Scope decision

No production HTML/CSS/JS was changed during this baseline-and-acceptance pass. Existing content already satisfies the checked static gates, and the remaining gaps require either external evidence or explicit real-business authorization. The protection and verification artifacts are the changed deliverables.
